# 7. Project Documentation

## Project Summary
This project demonstrates how script-controlled READ, WRITE, CREATE, and DELETE ACLs enforce record-level security in ServiceNow.

## Security Highlights
- Least-privilege permission structure
- Role-based authorization
- Branch-based record control
- Administrative override
- Separate CRUD ACLs
- Impersonation-based verification

## Outcome
The ACL model protects records from unauthorized viewing, creation, modification, and deletion.
