# 8. Project Demonstration

## Demonstration Flow
1. Log in to the ServiceNow instance.
2. Impersonate the EEE user.
3. Open `u_institution_details.list`.
4. Verify that EEE records are accessible.
5. Test users without the required role.
6. Impersonate Admin and verify full access.
7. Demonstrate CREATE using `bb2`.
8. Demonstrate WRITE using `bb3`.
9. Demonstrate DELETE using `bb4`.

## Final Result
The project demonstrates role-based and field-based record security using ServiceNow ACLs.
