# 1. Brainstorming & Ideation

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Idea
Implement record-level security in ServiceNow using ACLs, custom roles, a Branch field condition, and a script-controlled READ ACL.

## Key Idea
Only users with the required role can access the intended EEE records, while administrators retain full access.

## Main Operations
- READ
- CREATE
- WRITE
- DELETE
